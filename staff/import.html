NSL · Import CSV

Add / adjust inventory from a spreadsheet

Pick a .csv file. Each row becomes an inventory item. A row with an lpn/sku updates that item; a row with no key is added as new stock (handy for goods with no barcode, like Bella Canvas shirts).

RECOGNISED COLUMNS

lpn / sku · upc · asin · title · description · brand · category · condition · qty · msrp · cost · price

Column order doesn't matter; extra columns are ignored. Only title (or a key) is required.
